# P3：C01基督教沙面会堂独立样件

日期：2026-09-26。[打开C01](http://localhost:5174/prototypes/p2/#C01)。本轮交付可浏览的独立样件，尚未加入主城。

## 先纠正照片方位

上轮将2026年的三联彩窗照片泛称“主立面”，不准确。本轮把它明确区分为**北侧端墙**；南侧入口是带拱门、钟塔和穹隆顶的另一面。

定位依据相互补充：源轮廓`osm:w509641361`在南端有凸出部分；2026照片相机元数据位于北侧；2023南侧照片及2009转角照片显示入口塔身。[中国基督教网的堂会介绍](https://www.ccctspm.org/churchinfo/166)提供沙面南街60号身份及穹隆塔顶形态，[文物局2025年复函](https://wglj.gz.gov.cn/xxgk/bmwj/ywxx/wwl/content/post_10581109.html)明确区分60号会堂和69号牧师楼。

这支持当前的两面匹配，**不是像素级配准或实测方位角**。原候选照片记录已保留先前说明并添加纠正说明，避免后续继续沿用错误标签。

## 本轮几何

- 南侧：带实际凹入空间的三面拱门廊、钟塔拱窗与圆孔、分层檐带、低矮穹隆及十字架。
- 北侧：三联尖拱彩窗、两侧门洞、三个上部圆孔、三角山花和檐口。彩玻璃分色布局为估计，不是原图纹理或逐块复刻。
- 长侧墙：缺少清晰资料，保持灰色简化面；屋顶坡度和塔顶曲线为比例假设。
- 整体平面：保留源8点轮廓，包括南端凸出。使用现有plan-fit映射对齐对应控制点，不改变高度。

源主体约13.013×23.179m；南端凸出约3.751×3.662m；整体长边约26.841m。这些是源几何推导值，数值精细不代表现实精度。尤其南端源凸出与照片中门廊宽度的对应尚有疑点，不能以控制点误差为零宣称实际建筑1:1。

**主体檐高8.4m、脊高10.7m、总高19.4m均为展示估计。** 未取得绝对高度、墙厚、窗格或柱距的实测依据。2009、2023、2026年照片各自保留年代，不视为同期完整状态。

- “节点线位”叠加源轮廓；“证据着色”区分结构参考、估计和未覆盖面。
- 旧体量对照本轮没有建立，按钮禁用；这不表示基础城市不存在该源对象。
