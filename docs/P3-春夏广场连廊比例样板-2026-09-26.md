坐标：以两源节点中点作AEQD原点，展示x轴从春广场指向夏广场，z轴现取偏南的垂线方向（首版误取偏北，已修正镜像），y=0为假设平地。两侧灰色平面保留源建筑轮廓的局部裁切，**不是建筑实体、台阶或实际铺装**。不把建筑的layer=-1当成整栋地下建筑。

默认样板的悬空展示表示建筑实体尚未建立；不能以“内部射线贯通”宣称现实两端已接入、整条通道已验收。照片上被路牌遮住的细节、招牌和周边道路本轮没有补造。也未解除此前14条标线的待核状态。

照片仍使用原始CC0文件，无生成纹理。作者Ghaud Lnegauk，来源及SHA见[照片记录](research/p3-source-review-2026-09-26/photos.json)。模型中绿色仅表示照片支持结构类型或OSM线位，不表示精确尺寸；棕色为推定，灰色为未知。

## 文件与复现

- `tools/build-skybridge.py`：从原源快照提取两端节点、身份和裁切轮廓，单独生成参数包，保存源SHA-256及照片SHA-256。
- `prototypes/p2/skybridge.json`：源事实和所有尺寸假设，`measuredDeckElevationM=null`、`productionEligible=false`。
- `prototypes/p2/skybridge.js`：独立几何。P2包装入口加载S1，生产`src/models/detail-models.js`没有增加S1入口。
- `tests/skybridge.test.mjs`：真实节点归属、未知高度、内部射线贯通、可剖开部件、有限坐标、几何预算。

```sh
.research/p0-2026-09-25/.venv/bin/python tools/build-skybridge.py
npm test
node serve.mjs 5174
```
