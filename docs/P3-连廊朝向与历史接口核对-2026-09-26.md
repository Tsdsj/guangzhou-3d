## 修复：展示坐标产生了南北镜像

此前S1采用x指向夏广场、y向上、z指向北侧的组合，将地理东-北-天坐标转换为Three.js时产生了反射。长度检查不会发现这个问题，因为镜像不改变端点距离。

本轮新增回归：直接取源春广场边界相邻节点，计算其与样板裁切边界的交点，并验证落位方向。旧版本在该检查失败。随后将z改为偏南垂向，保留x从春端指向夏端、y向上：

```
x = east * ux + north * un
z = east * un - north * ux
```

`[ux, un]`是源桥轴在东、北方向的单位分量。完整三维变换保持右手性，源建筑轮廓不再被镜像。前侧围护、剖开部件、机位和地面标签同步到北侧观察方向。修复前的参数包保留为[skybridge-before.json](research/p3-skybridge-review/skybridge-before.json)，仅用于历史复核。

**这修正了软件坐标错误，不等于已确认照片朝向。** R6相机元数据换算到新坐标约为`[14.56,-8.89]m`，位于轴线北侧，仅能支持暂定观察方向。GPS未经独立校准，尚未取得像素配准或第二角度验证。UI因此仍显示“北侧·朝向推定”。
