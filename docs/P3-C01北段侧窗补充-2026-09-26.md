# P3：C01北段侧窗补充

日期：2026-09-26。[查看C01](http://localhost:5174/prototypes/p2/#C01)，点击“侧窗”查看新增部分与照片。本轮补了四个可辨认侧窗，没有调整门廊宽度或建筑高度，也未接入主城。

## 照片带来的新依据

新检查的2009年室内照片朝向北侧祭坛三联尖拱窗，两侧各可辨认两个半圆拱长窗，其中近处窗被画面边缘截断。它支持北段两侧存在拱窗，不能证明完整长侧的窗数、间距、外部装饰或2026年现状。

模型只在北段两侧各补两个开口。窗中心距北墙2.6m和6.6m、窗宽1.55m、窗高4.4m、窗台1.2m及参考墙段长9.6m均为**展示布局估计**，没有做像素量测。墙体实际开洞，玻璃退入洞内；外侧复杂窗套没有根据室内照片推造。未覆盖的南段继续保持灰色简化实墙。

“保留实墙”是未覆盖模型占位，不表示现实中南段没有窗。整面各6窗的百科描述仍属于未追溯的资料线索，本轮没有把局部照片扩展为六窗阵列。

## 门廊与高度的结论

源南端凸出可作为门廊/塔座的建模控制框，但本轮没有证明它就是完整外墙或檐口轮廓。正面仰拍中，门廊与大堂墙体深度不同，透视比例不能直接当成实际宽度比。因此保留源凸出约3.751×3.662m，不按观感任意放宽。

检索出现“檐高10.11m、塔高27.86m”的百科转述，尚未追溯到原始测绘页、基准和对应年代，没有升级为尺寸控制。[堂会自身介绍](https://church.cccmgd.com/jtjj.html)能支持身份沿革，未提供这些米制高度。现模型8.4m主体檐高、10.7m脊高、19.4m总高仍是展示估计。

状态明确记录在参数包：`sideWindowReview.dimensionStatus=estimated`、`totalWindowsPerSide=null`、`exteriorTrimVerified=false`、`currentAppearanceVerified=false`；`measuredHeightM=null`及`productionEligible=false`保持。
